Lumen 1.4 adds a live preview to every suggested doc change.

## What's new

- **Live preview.** Each suggestion opens with the rendered page next to the diff.
- **Broken link check.** Lumen flags links in a suggestion that point nowhere.
- **Faster sync.** Repositories with many docs now sync in about half the time.

## Why it matters

Reviewing a Markdown diff is slow when the change is mostly layout. The
preview lets your team approve a doc edit the way a reader will see it.
