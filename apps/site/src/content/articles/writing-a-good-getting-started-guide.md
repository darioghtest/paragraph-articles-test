A getting started guide has one job: get a new user to a working result.

1. **Start with the outcome.** Say what the reader will have built.
2. **Keep it short.** Ten steps or fewer.
3. **Use real commands.** Every snippet should run as written.
4. **Show the result.** End each step with what the reader should see.
5. **Link onward.** Point to the next guide, not to the whole reference.
