Lumen 1.3 adds a version switcher to every docs site.

## What's new

- **Version switcher.** Readers pick a version from the header and stay on the same page.
- **Version banners.** Pages for older versions show a banner that links to the latest.

Turn it on under **Settings → Versions**.
